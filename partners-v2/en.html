09 / Integration

Integration that fits your business

Your system connects to Jaree through an API to check eligibility, record redemptions or issue codes on demand.

Partner systemCommerce, booking, subscriptions or a custom system
HTTPS · API
Jaree ClubEligibility, codes and redemption records
Bearer API keysHMAC-SHA256Idempotency-Key
1

Scoped access

An API key for checks only, or checks and confirmation. Keep it on your server; revoke it when needed.

2

Test before activation

Test the integration for your chosen redemption method before submitting the benefit for review.

3

Track each operation

See the outcome of each request. If the connection fails, retry the same request without counting another redemption.

Code options and integration requirements+

Upload existing codes by CSV or connect your system to issue them on demand. You can also use Jaree’s verification page without an integration. Setup depends on your system; this presentation does not include ready-made commerce connectors.

10 / Integration in practice

How your system works with Jaree

Three operations: check eligibility, confirm redemption and issue codes on demand.

Your system → Jaree → Your systemHTTPS / JSON

The member presents their card or code. Your system checks eligibility and the available allowance with Jaree, without recording a use.

  1. 01Card or code
  2. 02Check with Jaree
  3. 03Eligibility result

The result is preliminary. Apply the benefit only after redemption is confirmed.
